Overview

Umar Butt Handwriting is a single-style (Regular 400) handwriting typeface. It ships as WOFF2 (web) and TTF (desktop / fallback), under the SIL OFL 1.1 — free for personal and commercial use, including embedding in websites, apps and documents.

Files & CDN endpoints

FilePurposeCopy
fonts/UmarButtHandwriting-Regular.woff2 Web font — all modern browsers
fonts/UmarButtHandwriting-Regular.ttf Desktop install, design tools, legacy fallback
css/umar-butt-handwriting.css Ready-made @font-face + helper class

CDN quick start (jsDelivr)

Add one line to your <head> — no downloads, no build step:

HTML
<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/gh/mohdumarbutt/umar-butt-handwriting@main/css/umar-butt-handwriting.css">

Or declare the face yourself with direct CDN URLs:

CSS — @font-face via CDN
@font-face {
  font-family: "Umar Butt Handwriting";
  font-style: normal;
  font-weight: 400;
  font-display: swap;
  src: url("https://cdn.jsdelivr.net/gh/mohdumarbutt/umar-butt-handwriting@main/fonts/UmarButtHandwriting-Regular.woff2") format("woff2"),
       url("https://cdn.jsdelivr.net/gh/mohdumarbutt/umar-butt-handwriting@main/fonts/UmarButtHandwriting-Regular.ttf") format("truetype");
}

Version pinning: @main tracks the default branch and is cached by jsDelivr. For production, pin a release tag — e.g. @v1.0.0 — for immutable, long-cached assets. After pushing updates to @main, you can refresh the cache with the jsDelivr purge tool.

Self-hosting (recommended for strict privacy)

Download the files (or copy the fonts/ folder from the repo) into your project, then:

CSS — self-hosted @font-face
@font-face {
  font-family: "Umar Butt Handwriting";
  src: url("/fonts/UmarButtHandwriting-Regular.woff2") format("woff2"),
       url("/fonts/UmarButtHandwriting-Regular.ttf") format("truetype");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}
HTML — preload for faster first paint
<link rel="preload" href="/fonts/UmarButtHandwriting-Regular.woff2"
      as="font" type="font/woff2" crossorigin>

Self-hosting means zero third-party requests — ideal for GDPR-sensitive projects and offline apps. Keep the LICENSE file alongside the fonts when you redistribute them.

Usage & fallbacks

CSS
.handwriting {
  font-family: "Umar Butt Handwriting", "Segoe Script", "Bradley Hand", cursive;
  font-weight: 400;
  font-synthesis: none; /* prevents ugly fake bold/italic */
}
  • Only Regular 400 exists — avoid requesting bold/italic weights.
  • Handwriting faces shine at display sizes (24px+); use a readable body font for paragraphs.
  • The CDN stylesheet also provides ready-made classes: .ub-handwriting and .umar-butt-handwriting.

Frameworks

Next.js — self-host with next/font/local for zero layout shift:

app/layout.tsx
import localFont from "next/font/local";

const handwriting = localFont({
  src: "../fonts/UmarButtHandwriting-Regular.woff2",
  display: "swap",
});

// <h1 className={handwriting.className}>Hello!</h1>

Tailwind CSS — register the family once, use font-handwriting everywhere:

tailwind.config.js
module.exports = {
  theme: {
    extend: {
      fontFamily: {
        handwriting: ['"Umar Butt Handwriting"', "cursive"],
      },
    },
  },
};

React / Vue / plain HTML — load the CDN stylesheet in your entry HTML (or import the CSS), then apply the family via class or inline style. Works in any stack that renders to the DOM.

Desktop installation (TTF)

  • Windows: right-click UmarButtHandwriting-Regular.ttf → Install for all users.
  • macOS: double-click the TTF → Install Font (Font Book).
  • Linux: copy the TTF to ~/.local/share/fonts/ and run fc-cache -f.

Restart open apps afterwards. The font appears as “Umar Butt Handwriting” in Word, Figma, Photoshop, Canva (uploaded fonts) and similar tools.

Performance tips

  • Preload the WOFF2 on pages where the font is above the fold.
  • Keep font-display: swap so text is never invisible.
  • Pin a version tag on jsDelivr for permanent edge caching.
  • Subset if you only need Basic Latin (requires pip install fonttools brotli):
Terminal — optional subsetting
pyftsubset UmarButtHandwriting-Regular.ttf \
  --unicodes="U+0020-007E" --flavor=woff2 \
  --output-file=UmarButtHandwriting-basic.woff2

Troubleshooting

The font doesn’t show up
Check the Network tab for a 200 response on the font file, verify the family name is exactly "Umar Butt Handwriting", and confirm you’re not requesting weight 700. On this site, the hero chip shows live font-load status.
CORS error when loading from another domain
jsDelivr serves fonts with Access-Control-Allow-Origin: *, so the CDN works everywhere. If you self-host on a separate asset domain, add that header there.
jsDelivr serves an old version
Branch refs like @main are cached. Purge the exact URL via the purge tool, or switch to an immutable release tag.
Brief flash of a different font
That’s the expected swap behavior. Preloading the WOFF2 usually removes it entirely.
Bold text looks strange
Only Regular exists. Set font-synthesis: none to stop browsers from faking bold, and use size/color for emphasis instead.

License FAQ

Can I use it in a commercial product?
Yes — websites, apps, SaaS, client work, logos, packaging, print, videos. No fees, no permission needed.
Do I need to credit the author?
Attribution is appreciated but not required for usage. If you redistribute the font files themselves, include the copyright notice and the OFL license text.
Can I modify the font?
Yes, under OFL 1.1 — but a Modified Version must be renamed, because “Umar Butt Handwriting” is a Reserved Font Name. Derivatives must also stay under OFL.
Can I sell the font?
Not by itself. You may bundle it with (and sell) software, themes or templates that include it, as long as the license travels along.
Can I embed it in a PDF or app bundle?
Yes. Documents created with the font are entirely yours and carry no license obligations.
