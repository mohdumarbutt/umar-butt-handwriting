## Web Usage

```css
@font-face {
  font-family: "Umar Butt Handwriting";
  src: url("https://cdn.jsdelivr.net/gh/mohdumarbutt/umar-butt-handwriting@v1.0.0/fonts/UmarButtHandwriting-Regular.woff2")
       format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

.handwriting {
  font-family: "Umar Butt Handwriting", cursive;
}
```

Then:

```html
<p class="handwriting">
  Hello from Umar Butt Handwriting.
</p>
```
