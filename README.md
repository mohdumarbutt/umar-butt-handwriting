# Umar Butt Handwriting — Public Font Website

Frontend showcase and live preview for **Umar Butt Handwriting** by **Mohd Umar Butt**.

## Quick setup

1. Put the WOFF2 file at `fonts/UmarButtHandwriting-Regular.woff2`.
2. Put the TTF file at `fonts/UmarButtHandwriting-Regular.ttf`.
3. Deploy this repository with GitHub Pages.
4. Replace `mohdumarbutt` in `js/app.js` with your GitHub username.
5. Create a GitHub release/tag named `v1.0.0`.
6. jsDelivr will serve the versioned WOFF2 URL.

The frontend includes:
- responsive landing page
- live editable font preview
- font size control
- character/glyph preview
- one-click CSS copy
- developer usage section
- font metadata/about section
