Quick start

Live in one line.

Free for websites, apps and commercial products — served by jsDelivr’s global CDN.

Option A — CDN stylesheet (easiest) 
<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/gh/mohdumarbutt/umar-butt-handwriting@main/css/umar-butt-handwriting.css">
Option B — raw @font-face 
@font-face {
  font-family: "Umar Butt Handwriting";
  font-style: normal;
  font-weight: 400;
  font-display: swap;
  src: url("https://cdn.jsdelivr.net/gh/mohdumarbutt/umar-butt-handwriting@main/fonts/UmarButtHandwriting-Regular.woff2") format("woff2"),
       url("https://cdn.jsdelivr.net/gh/mohdumarbutt/umar-butt-handwriting@main/fonts/UmarButtHandwriting-Regular.ttf") format("truetype");
}
Then use it anywhere 
/* CSS */
.handwriting {
  font-family: "Umar Butt Handwriting", cursive;
}

<!-- HTML — or use the ready-made helper class from Option A -->
<h1 class="handwriting">Hello, world!</h1>
<p class="ub-handwriting">Made with love by Umar.</p>

Production tip: pin a release tag instead of @main (e.g. @v1.0.0). Full guide in the documentation.
